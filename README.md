# SDKMorph

面向 Python 项目的 SDK 版本管理与自动升级插件。

SDKMorph 旨在帮助开发者识别 SDK 升级影响、迁移调用代码，并通过测试验证结果，最终审阅并接受代码修改。

**项目处于开发准备阶段，尚未实现插件功能，也未发布安装包。**

## 使用方式

插件发布后，预期使用流程如下：

1. 在桌面版 VS Code 中打开 Python 项目。
2. 配置自己的模型 API Key，检查 Python 和 Docker 环境。
3. 扫描项目依赖，选择需要升级的 SDK 与目标版本。
4. 查看影响分析，发起升级并等待代码迁移与验证。
5. 审阅代码差异和验证报告，选择是否接受补丁。

首版计划支持单个 Python 仓库中一个 SDK 的指定版本升级。实际安装步骤、支持范围与命令将在首个可用版本发布时补充。
