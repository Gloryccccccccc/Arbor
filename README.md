# Arbor

An extensible runtime for coding agents.

Arbor 是独立开发的轻量编码 Agent Harness，围绕会话分支、上下文压缩和可扩展工具执行，计划提供命令行交互和 SDK，支持代码阅读、修改与调试。

**项目处于设计阶段，核心代码与可安装版本尚未完成。**

## 使用方式

首个可用版本发布后，预期使用流程如下：

1. 安装 CLI，配置模型服务和自己的 API Key。
2. 在代码仓库中启动会话，选择本地或沙箱执行配置。
3. 输入代码理解、修改或调试任务，查看回复、工具调用和执行结果。
4. 根据需要补充要求、审批操作或取消执行。
5. 审阅代码变更，并继续或恢复已保存的会话。

安装命令、配置示例和支持平台将在首个可用版本发布时补充。
